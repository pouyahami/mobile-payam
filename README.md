# Mobix — Smartphone Storefront

فروشگاه مفهومی موبایل با طراحی پریمیوم، فارسی و RTL.

**Live:** https://mobile-payam.pages.dev/

## ویژگی‌های فعلی

- صفحه اصلی ریسپانسیو با هیرو، فیلتر برند و جستجوی فارسی
- صفحات برند و محصول
- **سبد خرید پایدار** (localStorage) + کشوی سبد
- **مقایسه تا ۳ محصول**
- قیمت‌های نمونه
- تصاویر محصول با تیمار تیره (dark-friendly)
- حالت‌های خالی بهتر (empty states)
- انیمیشن‌های قوی (fade, float, shimmer, orbit, hover 3D)
- SEO پایه

## جریان محلی

```bash
npx serve .
```

## قبل از پروداکشن

1. دامنه نهایی را جایگزین کنید
2. تصاویر را محلی و بهینه کنید
3. قیمت و موجودی واقعی وصل کنید
4. پرداخت و سفارش را پیاده‌سازی کنید

این مخزن هنوز پروتوتایپ است.
